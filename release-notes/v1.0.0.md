# v1.0.0 — First stable release

Météo Sentinelle turns the raw measurements of any weather station into
actionable frost and plant-disease alerts, using published agronomic
models rather than arbitrary thresholds.

This 1.0 marks a stability commitment rather than a pile of new
features: **entity names, state values and event payloads are now
considered settled.** Automations built on them will keep working.

## What you get

- **Frost risk per tree**, using the WSU T10/T90 critical temperature
  tables, evaluated against each tree's own growth stage — because
  −2 °C means nothing in dormancy and a great deal at full bloom.
- **Late blight** via the Hutton criteria, with the historical Smith
  Period exposed alongside for comparison.
- **Powdery mildew** via the Gubler-Thomas index, with a documented rain
  correction.
- **Automatic growth stage advancement** from accumulated growing degree
  days, monotonic, overridable, and switchable off per tree.
- **Treatment tracking** that accounts for both residual activity and
  wash-off, downgrading the displayed risk while protection lasts.
- **Two ready-made blueprints**, in English and French, installable in
  one click.
- A **fully translated interface** — English and French, English as the
  fallback for every other language.

## Submitted to the HACS default store

The repository now meets every acceptance criterion: public, described,
tagged with topics, issues enabled, hassfest and HACS workflows passing
without exclusions, and a published release for each version.

Until the submission is merged, the integration is still installed as a
custom repository. Nothing changes for existing users.

## Stability commitment

From now on:

- entity `unique_id`s and state values stay stable; any breaking change
  gets a major version and a migration;
- the `meteo_sentinelle_risk_changed` and
  `meteo_sentinelle_stage_advanced` payloads only gain keys, never lose
  them;
- the agronomic models stay traceable to their published source, and any
  deviation stays documented as such.

## Still true, and worth repeating

These models assume the pathogen is present and are not validated in the
field. They are an aid to vigilance, not plant-health advice.
