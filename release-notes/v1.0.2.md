# v1.0.2 — Available in the HACS default store

The submission to `hacs/default` has been merged: Météo Sentinelle now
appears directly in the HACS search. **No custom repository to add.**

Documentation only — no code change, nothing to do for existing users.

## What changed

- the installation instructions no longer describe adding a custom
  repository; installing is now search, install, restart;
- the badge says *HACS Default* instead of *HACS Custom*;
- a one-click **Open in HACS** button was added, using the My Home
  Assistant redirect — it only works now that the repository is
  referenced;
- the roadmap says the integration is available in the store rather than
  submitted to it.

Earlier release notes still describe the submission as pending. That is
deliberate: they are a dated record, not a description of the present.
