# v1.2.1 — Erreur de configuration de la carte

La carte pouvait afficher, à son ajout au tableau de bord :

```
Erreur de configuration
undefined is not an object (evaluating 'this._config.title')
```

Selon le navigateur, le message est formulé autrement, par exemple
`Cannot read properties of undefined (reading 'title')`.

## Ce qui change

Le frontend peut transmettre `hass` à l'éditeur visuel avant sa
configuration. L'éditeur essayait alors de s'afficher sans configuration et
échouait. Il attend maintenant de disposer des deux.

La carte elle-même avait la même fragilité, de façon plus discrète : dans cet
ordre, la lecture de l'historique échouait et restait bloquée, et la carte
ne montrait plus que le présent et le futur. L'historique se charge désormais
dès que la configuration arrive.

## Après la mise à jour

Forcez le rechargement de la page (Ctrl+F5, ou Cmd+Maj+R sur Mac), ou videz le
cache de l'application mobile, pour que le navigateur charge la nouvelle carte.

Cette version embarque aussi les précisions du README sur l'ajout de la carte
au tableau de bord.
