# v1.0.3 — Working links inside HACS

Documentation only — no code change, nothing to do for existing users.

HACS renders the README **outside the repository context**, so relative
links are never resolved: the *English* / *Français* switcher, the link to
`ARCHITECTURE.md` and the link to `LICENSE` all led nowhere for anyone
reading the integration page in HACS. They now point to absolute
`github.com` URLs and work in both places.

## What changed

- README links converted from relative paths to absolute GitHub URLs, in
  both the English and the French README;
- the English README says *License* rather than *Licence*, matching the
  spelling used throughout the rest of that file and the `LICENSE`
  filename — the French README keeps « licence », which is correct in
  French;
- macOS network-share leftovers (`.__wtest`, `.afpDeleted*`,
  `.smbdelete*`, `._*`) are now ignored by git; they never shipped in a
  release, this only keeps the working tree clean.
